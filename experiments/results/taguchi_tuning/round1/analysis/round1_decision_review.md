# 第一轮田口结果复核与第二轮决策建议

## 结论

建议进入第二轮局部细化，而不是现在将四因素主效应推荐组合直接冻结为最优参数。理由是四因素当前主效应最佳值全部位于已测范围边界，且推荐组合没有作为完整组合实际运行。该建议不是为了得到内部拐点；第二轮即使仍然单调或差异很小，也应如实报告。

本次仅利用已有960条结果离线分析、生成CSV及图，没有运行优化、decode、diagnosis或第二轮任务，没有修改原始结果、配置或算法代码。

## 数据与来源

- 16组×12实例×5 seeds=960条记录，全部有效完成，失败/缺失为0；每条40000 FE，共38400000 FE。
- manifest记录墙钟68363.74秒，约18.99小时；config记录初始并行进程数60。并发环境下的任务耗时不能直接当作单线程算子性能因果证据。
- 全部原始记录通过保存配置、身份、实例指纹、实际参数、FE、种群大小、非空非支配档案、目标值和来源校验。
- 当前正式算法、encoder、decoder的文件SHA256与服务器实验记录一致。
- 服务器运行Python 3.12.8，本次本地离线分析Python 3.9.6；运行器AST摘要不同，因此本次直接使用保存的experiment配置验证原始结果、计算离线指标，没有修改旧指纹，没有声称两个运行器字节级一致。对记录来源的一致性校验不等于重新执行服务器轨迹。
- 第一轮目录原来只有raw/config/manifest/OA；本次补生成analysis/和figures/，原有原始实验数据未覆盖。

## 主效应与稳健性

|因素|依水平递增的Mean NHV|极差|当前最好位置|
|---|---|---:|---|
|N：20/40/60/80|0.786890 / 0.773891 / 0.769540 / 0.764084|0.022806|下边界20|
|p_mut：0.05/0.15/0.25/0.35|0.767867 / 0.774093 / 0.775265 / 0.777180|0.009313|上边界0.35|
|rho：0.50/0.65/0.80/0.95|0.752636 / 0.761468 / 0.782410 / 0.797891|0.045254|上边界0.95|
|T_coop：5/15/25/35|0.794415 / 0.775646 / 0.760745 / 0.763598|0.033669|下边界5|

在当前范围内主效应响应幅度顺序：rho > T_coop > N > p_mut。不是独立因果贡献度，也不是显著性排序。

逐实例先对5 seeds求均值，再对某因素水平对应的4个OA组合求均值，得到以下描述性对比：

- T_coop=5对15，12/12实例主效应更好，平均差0.018769；对25也是12/12。
- rho=0.95对0.80，9/12实例更好、3/12更差，平均差0.015481。反例包括S1_P2_B2、S1_P3_B3、S8_P3_B2。
- N=20对40，9/12实例更好、3/12更差，平均差0.012999。
- p_mut=0.35对0.25，8/12更好、4/12更差，平均差仅0.001915；S8的P2/P3/P4三个实例均不偏好更高的0.35。

留一实例复核中，12次删除任一实例后，四因素最佳主效应水平仍分别为20、0.35、0.95、5。但p_mut第一/第二水平间优势最小可降至0.000457，因此不能把其微小优势称为明确显著收益。

上述胜负比较的是平衡正交设计的主效应，不是每个实例上只改变单一参数、其他参数完全固定的实验。L16无法充分辨识所有交互作用。

## 规模与结构边界

|规模|N主效应最好值|p_mut主效应最好值|rho主效应最好值|T_coop主效应最好值|
|---|---:|---:|---:|---:|
|S1|80|0.35|0.95|5|
|S4|20|0.35|0.95|5|
|S8|20|0.15|0.95|5|

S1的N=80和N=20主效应分别0.829857、0.823876，差约0.005980；S8则N=20为0.744129、N=80为0.708555。固定40000 FE下，N改变种群/档案联合容量以及搜索轮次数，因此不能推断任何预算下小N都更好。

S8在p_mut=0.15时主效应为0.733415，0.35时为0.719397，差0.014018。应在下一轮保留低变异端，而不是仅因总体均值单调就全部向0.35以上平移。

P1～P4及B1～B3均偏好rho=0.95、T_coop=5、N=20；p_mut偏好随分组变化：P2偏好0.25，P4偏好0.05，B1偏好0.15，其余分组偏好0.35。这里只保留描述性分组结论，不设计自适应参数。

## 档案容量公平性

完整NHV和统一40点上限NHV的16行组合排序完全一致。最大组合平均NHV损失约1.435e-6。

原始档案个体数超过40的运行有406条，但去除重复目标点后，唯一非支配目标点超过40的仅5条；所以该截断几乎不改变面积并不意外。

这支持当前排名并非主要由最终呈现点数超过40导致，但不证明档案容量不影响搜索。N_A=2N仍通过档案存储、协作及整个演化轨迹影响结果，N与N_A未被独立识别。

## 推荐组合与验证状态

主效应推荐：N=20、N_A=40、p_mut=0.35、rho=0.95、T_coop=5、FE_max=40000。

该完整组合不在16行中，没有实测NHV。不能将它与04混同：04的T_coop=15。04是当前实测最优组合；主效应组合只是待确认候选。

## 第二轮建议

若继续四因素四水平L16，建议采用以下局部细化范围，其他实验口径不变：

|因素|建议四水平|目的|
|---|---|---|
|N|10、20、30、40|测试20以下并细化20附近，同时保留40作较大容量参照；N_A继续2N|
|p_mut|0.15、0.25、0.35、0.45|保留S8偏好的0.15与当前总体最好0.35，适度探索更高值|
|rho|0.89、0.92、0.95、0.98|围绕0.95细化并适度提高，不直接触碰尚未验证的rho=1数值边界|
|T_coop|1、3、5、7|检查比5更频繁的协作，并覆盖5附近|

四组都是四水平等间距，只是后续实验建议，本次没有修改FACTOR_LEVELS、ROUND_NAME或构建/启动新实验任务。

优先关注rho、T_coop；N的联合容量效应次之；p_mut响应弱且存在规模差异，不宜激进上移。该设计旨在检验范围边界与稳健性，不保证一定出现内部最优点。

如果计算资源有限，可以先对未实测的主效应推荐组合做独立确认，与04及S8较强的10比较，再决定是否投入完整第二轮。这是较低成本替代方案，不等同于已经完成第二轮校正。

最终参数冻结前应有推荐组合的实际确认结果，且不能只看总体平均而忽略S8。跨轮NHV参考尺度重新建立，不能把两轮各自的NHV绝对数值直接相减作为改进幅度；需要同尺度重评或统一确认比较。

40000 FE是用户本轮固定的计算预算；此前收敛审计未证明该预算充分收敛。本轮结果只支持固定40000 FE下的参数校正，不证明所有预算下的渐近参数最优。
